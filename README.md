# 학생 상담 예약

학생이 학번·이름·비밀번호를 입력하고 빈 시간대에 상담을 예약하는 웹 앱입니다.

- 화면: GitHub Pages (`index.html` 예약, `admin.html` 관리자, `app.js`, `admin.js`, `api.js`, `style.css`, `config.js`)
- 서버·저장: Google Apps Script + 구글 시트 (`apps-script/`)

## 동작 규칙

처음 값은 아래와 같고, **관리자 페이지 > 설정** 에서 코드 없이 바꿀 수 있습니다.

| 요일 | 아침 | 점심시간 | 방과후 |
|---|---|---|---|
| 월·금 | 08:20~ | 13:30~ | 16:10~ |
| 화·수·목 | 08:20~ | 13:30~ | 17:10~ |

- 오늘부터 28일 뒤까지, 마지막 상담 날짜(2026-11-06)까지 예약할 수 있습니다. 한 시간대에는 한 명만 예약됩니다.
- 오늘 날짜는 시간대 시작 시각이 지나면 마감됩니다.
- 예약할 때 정한 비밀번호로 **내 예약 확인 → 취소 / 변경** 할 수 있습니다. 비밀번호는 시트에 해시로만 저장됩니다.
- 비밀번호를 5번 틀리면 10분 동안 그 학번으로 조회할 수 없습니다.
- 다른 학생에게는 "예약됨"만 보이고 이름은 보이지 않습니다.

설정은 Apps Script 의 스크립트 속성 `SETTINGS` 에 저장됩니다. 한 번도 저장하지 않았으면 `Code.gs` 의 `DEFAULT_SETTINGS` 를 씁니다.

## 1. Apps Script 배포

1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (예: "상담 예약").
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 를 켜고, `appsscript.json` 을 `apps-script/appsscript.json` 내용으로 바꿉니다. (시간대 `Asia/Seoul`)
5. 함수 목록에서 `setup` 을 선택하고 **실행** → 권한 승인. 시트에 `예약`, `휴무일` 탭이 생깁니다.
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
7. **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**: 이름 `ADMIN_PASSWORD`, 값에 관리자 비밀번호. (GitHub 에 공개되는 코드에 비밀번호를 넣지 않으려고 여기에 저장합니다)
8. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됩니다. (URL 은 그대로)

## 2. GitHub Pages 배포

1. `config.js` 의 `API_URL` 에 위에서 복사한 URL 을 넣습니다.
2. GitHub 에 새 저장소를 만들고 이 폴더를 올립니다.
   ```bash
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 저장하면 몇 분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

`API_URL` 을 비워 두면 브라우저에만 저장되는 **데모 모드**로 동작해서 화면만 미리 볼 수 있습니다. (데모 서버는 `api.js` 에 있고, 처음 설정은 `Code.gs` 의 `DEFAULT_SETTINGS` 와 같게 맞춰 두었습니다.)

## 선생님용 관리

`https://<아이디>.github.io/<저장소>/admin.html` 에서 `ADMIN_PASSWORD` 로 들어갑니다.

- **달력**: 예약 기간의 현황을 주 단위로 봅니다. 칸마다 예약한 학생의 학번·이름이 보입니다.
- **목록**: 날짜별 표. "취소·지난 예약도 보기" 로 전체 기록도 볼 수 있습니다.
- **설정**: 코드를 고치지 않고 바로 바꿉니다. 저장하면 학생 화면에 곧바로 반영됩니다.
  - 예약 화면 제목, 안내 문구
  - 예약 기간 (오늘부터 며칠 뒤까지, 마지막 상담 날짜)
  - 상담 시간대: 이름, 시작 시각, 열리는 요일(월~금 체크). 줄 추가·삭제 가능
  - 휴무일: 날짜와 사유
  - 바꾼 설정 때문에 없어지는 시간에 이미 예약이 있으면, 저장 전에 그 목록을 보여 주고 확인을 받은 뒤 그 예약들을 취소합니다.

구글 시트에서도 관리할 수 있습니다.

- **예약 목록**: `예약` 탭. 상태가 `예약` 인 행이 유효한 예약, 취소하면 `취소` 로 바뀝니다.
- **휴무일**: `휴무일` 탭 A열에 날짜(`2026-10-20`), B열에 사유를 적어도 설정의 휴무일과 똑같이 적용됩니다.
- **직접 취소**: `예약` 탭에서 상태를 `취소` 로 바꾸면 그 자리가 다시 열립니다.
- 학생이 비밀번호를 잊으면 선생님이 직접 취소해 주고 다시 예약하게 하면 됩니다.
